Family Finance v1.1.4 PUBLIC — Category profile privacy and lifecycle fix.

Category profile entries are no longer recreated from History on each render. Existing locally stored category profiles are retained. Use the optional explicit Add missing categories from local History button to restore missing categories. Unused categories may be deleted with confirmation; original transactions are untouched.

The PUBLIC package contains no user transactions or user-specific category lists. Back up local JSON before deploying. Do not upload private backup or import files to a public repository.
